# Self-hosted fonts

These unmodified WOFF2 files are served from this site. Visitors make no requests to Google Fonts or a font CDN.

| File                              | Download source                                                                                                                   | Licence                        |
| --------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- | ------------------------------ |
| `manrope-latin-wght-normal.woff2` | [Fontsource Manrope 5.3.0](https://cdn.jsdelivr.net/npm/@fontsource-variable/manrope@5.3.0/files/manrope-latin-wght-normal.woff2) | [SIL OFL 1.1](manrope-OFL.txt) |
| `dm-mono-latin-400-normal.woff2`  | [Fontsource DM Mono 5.3.0, regular](https://cdn.jsdelivr.net/npm/@fontsource/dm-mono@5.3.0/files/dm-mono-latin-400-normal.woff2)  | [SIL OFL 1.1](dm-mono-OFL.txt) |
| `dm-mono-latin-500-normal.woff2`  | [Fontsource DM Mono 5.3.0, medium](https://cdn.jsdelivr.net/npm/@fontsource/dm-mono@5.3.0/files/dm-mono-latin-500-normal.woff2)   | [SIL OFL 1.1](dm-mono-OFL.txt) |

Manrope covers weights 200–800. DM Mono provides weights 400 and 500. These are Latin subsets; other characters use the CSS fallback fonts. The accompanying licence files preserve the upstream copyright notices and licence text.
